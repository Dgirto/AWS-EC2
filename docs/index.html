¿Qué es y para qué sirve?

Este conector permite al agente de Ruvic consultar y controlar instancias de Amazon EC2: listar instancias, iniciar o detener una instancia, y consultar su estado actual.

Este conector modifica infraestructura real start_instance y stop_instance cambian el estado real de una instancia. Úsalo con cuidado sobre instancias productivas.
Operación Qué hace
ec2.list_instances Lista las instancias de la región configurada
ec2.start_instance Inicia una instancia detenida
ec2.stop_instance Detiene una instancia en ejecución
ec2.get_instance_state Consulta el estado actual de una instancia

Prerrequisitos

  • Al menos una instancia EC2 ya creada en tu cuenta de AWS.
  • Acceso a la consola de AWS IAM para crear un usuario dedicado.
  • La región de AWS donde viven las instancias a administrar.

Configuración en el fabricante

Vas a crear un usuario IAM dedicado para Ruvic. Se recomienda restringir el control (start/stop) por tag, para que el agente solo pueda actuar sobre instancias explícitamente marcadas.

  1. Crea un usuario IAM dedicado.

    En IAM → Usuarios → Crear usuario. Solo acceso programático, sin acceso a la consola.

  2. Marcá las instancias que el conector podrá controlar.

    Agregá el tag RuvicManaged=true a las instancias donde querés permitir start/stop desde Ruvic.

  3. Crea una policy con el mínimo privilegio necesario.

    Adjuntá una policy en línea que restrinja el control por ese tag:

    {
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "ec2:DescribeInstances",
        "ec2:DescribeInstanceStatus",
        "ec2:StartInstances",
        "ec2:StopInstances"
      ],
      "Resource": "*",
      "Condition": {
        "StringEquals": { "aws:ResourceTag/RuvicManaged": "true" }
      }
    }
  ]
}
  4. Genera las claves de acceso.

    En "Credenciales de seguridad" del usuario, creá un Access Key. Guardá el Access Key ID y el Secret Access Key — el secreto solo se muestra una vez.

Permisos requeridos

Permiso Para qué sirve
ec2:DescribeInstances Listar instancias (list_instances, test de conexión)
ec2:DescribeInstanceStatus Consultar estado (get_instance_state)
ec2:StartInstances Iniciar una instancia (start_instance)
ec2:StopInstances Detener una instancia (stop_instance)
Nota No se otorgan permisos de administración (ec2:RunInstances, ec2:TerminateInstances, cambios de red o grupos de seguridad).

Configuración en Ruvic

Entrá a Settings → Conectores, buscá la tarjeta AWS EC2 y pulsá Configurar.

Campo del formulario Valor
Access Key ID El Access Key ID generado en el paso anterior
Secret Access Key El Secret Access Key generado (se guarda cifrado)
Región de AWS La región donde viven las instancias (ej. us-east-1)

Probar conexión — la plataforma listará instancias de la región configurada para confirmar credenciales y acceso.

Verificación

  1. Test de conexión exitoso.

    El botón "Probar conexión" debe responder con éxito listando instancias de la región.

  2. Prueba mínima con el agente.

    Abrí una conversación nueva y pedile:

    "Listame las instancias EC2 y su estado."

    El agente debe devolver el listado real de instancias con su estado (running/stopped).

Solución de problemas

Mensaje / síntoma Causa probable y solución
"Credenciales inválidas o sin permiso IAM suficiente" Access Key inválida/rotada, o la policy no incluye el permiso ni el tag necesario para la operación.
"La instancia no existe o no es accesible" ID de instancia mal escrito, o la instancia está en otra región distinta a la configurada.
"La instancia no está en un estado válido para esta operación" Intentaste iniciar una instancia ya en ejecución, o detener una ya detenida. Consultá el estado primero con get_instance_state.
"No se pudo conectar al servicio" (timeout) Región de AWS incorrecta, o problema de red temporal. Reintentá.
El conector aparece "Sin configurar" tras guardar Algún campo obligatorio quedó vacío. Completá Access Key ID, Secret Access Key y Región.

Preguntas frecuentes y notas de seguridad

¿El agente puede iniciar o detener cualquier instancia de mi cuenta?

Solo si la policy IAM lo permite. Se recomienda restringir start/stop a instancias con un tag específico (ej. RuvicManaged=true), así el agente nunca puede tocar instancias no marcadas explícitamente.

¿Dónde queda guardado el Secret Access Key?

Como secreto en el almacén de credenciales de la plataforma. La interfaz nunca vuelve a mostrarlo; solo indica "definido".

Rotación de credenciales

Recomendado cada 90 días: generá un Access Key nuevo en IAM, actualizalo en el formulario del conector, y desactivá el anterior una vez confirmado que el nuevo funciona.

¿Qué hago si las claves se comprometen?

  1. Desactivá el Access Key inmediatamente en IAM.
  2. Revisá la actividad reciente en AWS CloudTrail (buscá acciones StartInstances/StopInstances inesperadas).
  3. Generá un Access Key nuevo y actualizalo en el formulario.
Buenas prácticas Restringí start/stop por tag, nunca uses un usuario con permisos sobre toda la cuenta; y recordá que detener una instancia productiva puede causar una interrupción de servicio real.
